## 多密钥 Key 级优先级（严格优先）

### 语义
- 每个 Key 可设优先级（默认 0）；**选 Key 时永远先用最高优先级的可用 Key**，同优先级内随机分流；高优 Key 全部不可用（被禁用）时自动落到下一层。
- 与渠道级优先级心智一致；默认值 0 = 现行为，完全向后兼容。
- random 与 polling 两种模式都生效：random = 最高层内随机；polling = 最高层内环形轮询。
